## `Zone` fields

| Field | Type | Description |
|---|---|---|
| `owner` | `Tid` | Owning thread while locked; undefined when unlocked. |
| `locked` | `_Atomic int` | 0 = free, 1 = held. Contended waiters spin-check then block. |
| `ntfn` | `Handle` | Kernel notification object waiters block on. |

**Errors**

| Code | Condition |

### `ZoneDestroy`

```c
Err ZoneDestroy(Zone *z)
```

The zone must be unlocked and have no waiters. Using `z` afterwards is UB.

**Parameters**

| Name | Description |
|---|---|
| `z` | Zone to destroy. |

**Returns** — `ERR_OK` on success.

**Errors**

| Code | Condition |
|---|---|
| `ERR_INVAL` | `z` is NULL or uninitialised. |
| `ERR_BUSY` | The zone is held or has waiters. |

### `ZoneEnter`

```c
Err ZoneEnter(Zone *z)
```

**Parameters**

| Name | Description |
|---|---|
| `z` | Initialised zone. |

**Returns** — `ERR_OK` once the zone is held by the caller.

**Errors**

| Code | Condition |
|---|---|
| `ERR_INVAL` | `z` is NULL or uninitialised. |
| `ERR_DEAD` | Backing notification object was destroyed. |

> **Note:** Blocking. Recursive entry by the owner is undefined behaviour.
