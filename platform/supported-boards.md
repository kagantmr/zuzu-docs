The current list of supported boards are:

| Board | Support level |
| --- | --- |
| Raspberry Pi 4 | secondary platform, no drivers except pl011 |
| vexpress-a15 | main platform, near-perfect driver support |
| QEMU `virt` | kernel boots, no drivers except pl011 |
