Want to port zuzu to a board you like?

## Requirements

1. A DTB file
2. If you prefer, a bootloader such as U-Boot
3. (currently) A board folder in the arch/your_arch/` path.

Porting is currently slightly discouraged, as the zuzu HAL is still under development.
